# Category Permissions Viewer

Локальное read-only приложение для анализа партнерских whitelist по дереву категорий.

## Запуск

Откройте `../dist/category-permissions.html` в современном браузере, затем выберите:

1. Excel с разрешениями.
2. JSON с деревом категорий.

Файлы читаются только в браузере и никуда не отправляются. После закрытия страницы данные не сохраняются.

## Excel

Используется первый лист книги. Обязательные столбцы:

- `partnerId`: текстовый код партнера;
- `categoryIds`: один целочисленный ID категории в строке; также принимается заголовок `categoryId`;
- `allow`: `yes` или `no` без учета регистра.

Пустые строки пропускаются. Порядок строк каждого партнера сохраняется и определяет порядок `yes`/`no`-батчей.

## JSON

Принимается массив категорий или объект `{ "categories": [...] }`. Поля категории:

- `categoryId`: целое число;
- `parentid`: ID родителя или `null` для корня;
- `name`: запасное название;
- `displayname`: основное отображаемое название;
- `treepath`: массив ID родителей без ID самой категории.

Дерево строится по `parentid`. Несовпадение `treepath` показывается как предупреждение.

## Сборка

```powershell
./app/build.ps1
```

Скрипт встраивает `styles.css`, `app.js` и локальную standalone-сборку SheetJS в один файл `dist/category-permissions.html`.

Тестовые файлы находятся в `app/samples`. После `npm install` и `npx playwright install chromium` браузерный smoke-тест запускается командой:

```powershell
node app/e2e.mjs
```

Для чтения и записи Excel используется SheetJS Community Edition `0.20.3`; лицензия сохранена в `app/vendor/SHEETJS-LICENSE.txt`.
